# TinyScribe

Fine-tune Qwen3.5-9B to read Indian forms (English, Hindi, Tamil, Bengali) into JSON, then quantize it to a 4 GB language-model file (about 4.5 GB with its vision projector) that runs offline on a MacBook.

**Status:** Week 1 (data, scorer, baseline). Plan: [v5](docs/TinyScribe%20—%204-Week%20Resume%20Project_v5.md) · Progress: [weekly reports](docs/reports/).
